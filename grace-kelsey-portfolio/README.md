# Grace Kelsey portfolio

A lightweight, four-page static portfolio designed for GitHub Pages. It uses plain HTML and CSS, so it does not need a build step or package installation.

## Before publishing

1. The graduation photo is at `assets/grace-kelsey-headshot.jpg` and is already connected on the home page.
2. The résumé PDF is at `assets/Grace-Kelsey-Resume.pdf` and is connected to the home page download button.
3. The leadership development plan PDF is at `assets/Leadership-Development-Plan.pdf` and is connected to the home page download button.
4. Review the wording and details, especially education dates and the certification / award names, before publishing.

## Publish

Upload the files and the `assets` folder to the root of your GitHub repository, then enable GitHub Pages for the repository's main branch and root folder. Open `index.html` locally to preview the site.

The Google Fonts connection requests Source Sans 3. System fallbacks are included if the font is unavailable.
